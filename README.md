Deploy a simple static website using GitHub Pages.

- CSS3
- Git
- GitHub
- GitHub Pages

## Project Files

- `README.md` - Project documentation.

## Implementation Steps
1. Created a static website using HTML and CSS.
2. Created a GitHub repository for the project.
3. Uploaded the project files to the repository.
4. Enabled GitHub Pages using the main branch and root folder.
5. Verified the published website in a web browser.
